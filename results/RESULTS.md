# Results

Generated by `go run ./cmd/bench` from `results/data/*.jsonl`: the latest record per app, form and library. Units: ns per record.

- **compute** is the program's own timed loop (arithmetic and in-memory formatting of the output; no file I/O, no input decoding). It is the fastest sample over 3 processes, and the ranking key.
- **median** and **p10–p90** cover the second half of each process's samples (the first half counts as warm-up). A wide range means the value is not stable.
- **xcheck** is the runner's own clock divided by **compute**: it times a run with twice the samples and divides the extra wall time by the extra passes. Near 1.00 means the program's timer agrees; ⚠ marks a ratio outside 0.90–1.25 (banking 0.90–2.50, because it rebuilds its accounts between passes outside the timed loop).
- **whole** is one gated run from process start to exit, fastest of N. **startup** is a do-nothing Go program launched the same way, so whole − startup is the program's own work.
- **correct**: ✓ = every gated run matched the golden byte for byte; *n*/*m* = output files matched (risk); ✗ = a mismatch in at least one run.
